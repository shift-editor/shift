# F0.1 — Stroke data model spike

**Branch:** `explore/strokes`  
**Date:** 2026-11-20  
**Status:** recommendation draft (repo survey)

## Today’s anchors

- `Contour`: `id`, `points`, `closed` only — no stroke role ([`contour.rs`](../../crates/shift-font/src/ir/contour.rs)).
- `GlyphLayer`: contours, components, anchors, guidelines, `lib`.
- Typed lib pattern: `Grid` ↔ `com.shift.grid` with intents and UFO round-trip ([`grid.rs`](../../crates/shift-font/src/ir/grid.rs), UFO tests).
- Interpolation: structure via `LayerMatch`; scalars via point x/y, width, components — **lib and nib metadata do not interpolate yet**.

## Options (summary)

| Option | Idea | Best for spike | Main risk |
| ------ | ---- | -------------- | --------- |
| **A** | `ContourRole` + stroke refs on contour | Long-term IR clarity | Wide blast radius (DTOs, pack, bridge) |
| **B** | Parallel skeleton layer per glyph | UFO layer familiarity | Cross-layer matching; fights one-layer-per-source model |
| **C** | `com.shift.stroke` on layer lib, contour IDs as keys | Fast CP0, UFO round-trip | Geometry/lib desync; B5 needs value-vector extension |

## Recommendation

**Phased hybrid C → A** (confidence **medium**):

1. **Now:** layer lib `com.shift.stroke` — roles, style ids, optional `nibTrack` keyed by `PointId`; skeleton paths only in `contours` (outlines computed, not stored).
2. **After CP0:** promote `ContourRole` on `Contour`; keep lib as UFO adapter (`to_lib` / `from_lib` like grid).

**Reject B** for v1 unless desync experiments fail on C.

## One-day validation (before product Rust)

1. Fixture glyph + `com.shift.stroke` on layer lib → MessagePack round-trip.
2. UFO export/import preserves stroke lib.
3. Deleting skeleton contour → orphan lib detected or cleaned on replace.
4. Two masters, same topology, different nib width in lib → document that lib does not blend (B5 gap).
5. `LayerMatch` complete with skeleton-only contours.
6. Run [`spike/exact_offset`](./spike/) outline — **do not** write result into layer.

## F0.2 shapes (conceptual)

- `StrokeStyle`: width, cap, join, miterLimit; font-level presets in `com.shift.strokeStyles`.
- `NibSample`: width, optional height, angle per `PointId`.
- Solver (F0.3): ephemeral `outline(skeleton, style | track) -> contours`.
