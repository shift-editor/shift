## How to run

### Option A — `pointer-probe.html` (recommended)

1. From repo root, open the probe without a server:
   - **Finder:** double-click `explorations/strokes/pointer-probe.html`, or
   - **Terminal:** `open explorations/strokes/pointer-probe.html` (opens default browser), or
   - **Electron:** run Shift dev (`pnpm dev`), open DevTools on any window → **Console** →  
     `window.open('file://' + '<absolute-path-to>/explorations/strokes/pointer-probe.html')`  
     (replace with your machine path; avoid pasting paths that contain secrets).
2. Click **Capture area** (large pad). Move the pointer slowly, then quickly; for pen, hover then press with light/heavy pressure, tilt barrel, twist if your pen supports it.
3. Use the on-screen **Event log** and **Live** row. For each hardware row below, perform the **exercise** and record what you see (not what the spec promises).
4. Optional: click **Freeze log** before copying values into the matrix.

### Option B — Shift glyph canvas

1. `pnpm dev` (or `nix develop --command pnpm dev`).
2. Open a glyph, select a drawing tool that receives pointer events on the canvas.
3. DevTools → **Console**, paste the snippet from [Appendix: Shift canvas snippet](#appendix-shift-canvas-snippet).
4. Draw on the canvas with each device; copy logged fields into the matrix.

### Exercises (same for every device)

| Step | Action | What to note |
| ---- | ------ | ------------ |
| 1 | Move without button down | `pointerType`, whether `pressure` stays `0` or drifts |
| 2 | Light click / tap | min `pressure` while down |
| 3 | Firm click / heavy press | max `pressure` |
| 4 | Pen only: hover above surface | pressure, tilt, twist while **not** in contact |
| 5 | Pen only: slow stroke at ~45° pen angle | `tiltX`, `tiltY` range and whether they flip sign |
| 6 | Pen only: barrel roll / rotate pen | `twist` changes? |
| 7 | Pen only: finger on barrel button (if mapped) | `tangentialPressure` or button-only? |
| 8 | Sidecar only: Apple Pencil vs finger | separate rows if `pointerType` differs |

## Appendix: Shift canvas snippet

Paste in DevTools while the glyph canvas is focused. Remove when done (`removeProbe()`).

```js
(() => {
  const el =
    document.querySelector("canvas") ??
  document.querySelector("[data-canvas]") ??
    document.elementFromPoint(innerWidth / 2, innerHeight / 2);
  if (!el) {
    console.warn("C1.1: no canvas found");
    return;
  }
  const log = (e) => {
    const { pointerType, pressure, tiltX, tiltY, twist, tangentialPressure } = e;
    if (e.type === "pointermove" && e.buttons === 0) return;
    console.log(e.type, {
      pointerType,
      pressure,
      tiltX,
      tiltY,
      twist,
      tangentialPressure,
      buttons: e.buttons,
    });
  };
  for (const t of [
    "pointerdown",
    "pointermove",
    "pointerup",
    "pointercancel",
  ]) {
    el.addEventListener(t, log, { capture: true });
  }
  window.removeProbe = () => {
    for (const t of [
      "pointerdown",
      "pointermove",
      "pointerup",
      "pointercancel",
    ]) {
      el.removeEventListener(t, log, { capture: true });
    }
    delete window.removeProbe;
    console.log("C1.1 probe removed");
  };
  console.log("C1.1 probe on", el, "— call removeProbe() when done");
})();
```
